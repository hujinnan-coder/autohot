
【汽车领域翻译与用词规则 — 本平台是汽车行业内容，严格遵守】

1. 歧义默认值：以下词在中文里有别的意思，**一律按汽车行业的含义理解和翻译**：
   - Recall = 召回（不译“回忆”“召回率”）
   - Delivery / Deliveries = 交付量（不译“快递”“配送”）
   - Registration(s) = 上险量或注册量（按原文所指市场，不译“登记注册”）
   - Wholesale / Retail = 批发量 / 零售量（销量口径，不译“批发业”“零售业”）
   - Trim = 配置或版本（不译“修剪”）
   - Facelift = 中期改款；All-new / Next-generation = 全新一代、换代
   - Platform = 平台或架构（整车平台，不是互联网平台）
   - Range = 续航里程；Charging = 充电；Battery swap = 换电
   - Dealer / Dealership = 经销商 / 经销店；Agency model = 代理制
   - OEM = 整车厂、主机厂；Tier 1 = 一级供应商
   - Incentive = 终端优惠或购车补贴（按语境）
   - Crossover = 跨界车；Pickup = 皮卡；Sedan = 轿车；Hatchback = 两厢车
   - EREV / Range extender = 增程；PHEV = 插电混动；BEV = 纯电；ICE = 燃油车；NEV = 新能源车

2. 品牌、公司和车型名：
   - 在中国有通行中文名的，用中文名：Volkswagen 大众、Toyota 丰田、Mercedes-Benz 奔驰、BYD 比亚迪、Great Wall 长城汽车、Li Auto 理想汽车、NIO 蔚来、XPeng 小鹏、CATL 宁德时代、Bosch 博世、Stellantis 可保留英文。
   - 中国品牌的海外名对回国内叫法：BYD Seal = 比亚迪海豹、BYD Atto 3 = 比亚迪元 PLUS、BYD Dolphin = 比亚迪海豚、MG4 保留。拿不准对应国内哪款车时保留原文名，不要猜。
   - 车型的字母数字代号一字不改：Model Y、ID.4、SU7 Ultra、L9、ES6、G6、bZ3X、iX3、EQE、Q6 e-tron。
   - 没有通行中文名的海外品牌和公司保留原文：Rivian、Lucid、Waymo、Mobileye、Momenta。
   - “理想”“大众”“现代”“长城”“红旗”这类也是日常用词的品牌名，在可能混淆处写全称（理想汽车、大众汽车、现代汽车、长城汽车）。

3. 以下缩写**保留英文**：SUV、MPV、OTA、NOA、ADAS、FSD、L2/L3/L4、C-NCAP、Euro NCAP、IIHS、NHTSA、CLTC、WLTP、EPA、CTB、CTC、800V、kWh、kW、V2G、Robotaxi、eVTOL。

4. 数字、金额和单位**一字不改**保留：
   - 售价、销量、续航、功率、电池容量、加速、补贴金额、关税税率必须保留原文的阿拉伯数字和单位；不要把 $7,500 改成“数千美元”，不要把 12.98 万元改成“约 13 万元”。
   - 外币金额保留原币种，可以不换算；换算时写明“约合”。
   - 销量数字写明口径和时间范围（批发、零售、上险、交付；周、月、累计），原文没写口径时不要补。
   - 同比、环比、市占率的百分数照录，不四舍五入。

5. 未经证实的指控、车主维权、事故原因和网传消息：写明是谁的说法，当事企业没有回应时写“官方未回应”；不替任何一方下结论，不写“实锤”“坐实”“翻车”这类定性词。
