
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：品牌名 / 车型名 / 公司名 / 机构名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 口号 / 没信息量的 teaser（如 "它来了"、"今晚见"、"Day 1"、"重磅发布"、"官方回应"）时，结合【来源】和正文把主体补进标题。例：原标题 "官方回应" + 来源 "某品牌法务部" + 正文回应的是某车型起火传闻 → "某品牌回应某车型起火传闻：电池未受损"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体车型时，用上位词（如"一款中型纯电 SUV"）兜底，绝不凭"行业常识"编一个具体车型 / 版本 / 价格 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Analysis / Review / First Drive / 试驾 / 解读 / 专访 这类解释、分析、评测或访谈标题，中文标题必须保留这个类型；不能因为正文谈到一款已经存在的车型或新数据，就改写成“发布 / 上市 / 推出”。只有原标题明确宣布了发布、上市、调价或实施，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的品牌、车型、公司名。
   例：原标题 "Why BYD's Seal 06 undercuts every rival in Europe" → "比亚迪海豹 06 为何在欧洲比所有对手都便宜"，不能写成 "比亚迪海豹 06 在欧洲上市"。
   例：原标题 "First drive: a week with the new platform" + 来源和正文明确是大众 ID.3 换代车型 → "试驾换代大众 ID.3：新平台开一周的感受"，不能只写成缺主体的 "新平台开一周的感受"。
6. 本条的动作和背景里的旧发布要分清：原文把发布或上市写成过去的事（“Last week we launched …”“上月上市的…”“此前发布的…”），本条是在做试驾、解读、交付报道或再次推广时，标题写试驾、解读或交付，把上市交代成此前的事；不能写成“发布 / 上市 / 推出”，否则读者会当成今天的新闻。亮相、预售、上市、交付是四个不同阶段，按原文所处的阶段写，不往前也不往后挪。
   例：正文 "上月上市的某车型今日开启全国交付，首批车主在 30 城提车" → "某车型开启全国交付，首批覆盖 30 城"，不能写成 "某车型上市"。
